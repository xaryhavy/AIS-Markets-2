# AIS Markets — Autonomous Trading System
Fully autonomous but owner-controlled algorithmic trading system for cTrader demo accounts.

## Features
- ✅ Starts **ON** by default — owner can toggle OFF at any time
- ✅ Preferences persist across restarts/reconnections
- ✅ Live trading **LOCKED** by default — explicit approval required
- ✅ Daily/weekly/monthly loss caps enforced
- ✅ Recovery fence: unclean shutdown → review required
- ✅ Clean dashboard — no debug text
- ✅ All decisions logged (trade & no-trade)
